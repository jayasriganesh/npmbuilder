# 📦 npmcmd

**npmcmd** is a premium, focused developer utility designed to get you the correct npm install commands instantly. No more second-guessing versions or flags—just search, select, and copy.

## ✨ Features

- **Instant Search**: Powered by the official npm registry API with intelligent suggestions.
- **Smart Toggle**: Switch between `npm`, `yarn`, `pnpm`, and `bun` instantly.
- **Multi-Command Clipboard**: Collect multiple package commands and copy them all at once.
- **History Tracking**: Keep track of your recent package searches locally.
- **Keyboard Shortcuts**: Native-feeling experience with `/` to search and `⌘ + C` to copy.
- **Premium Dark Aesthetics**: A beautiful, editorial-inspired industrial design.

## 🚀 How to Use

1. **Search**: Type a package name (e.g., `react`) in the search bar. Use `Enter` or the "Generate" button.
2. **Select Type**: Toggle between `dependency` and `devDependency`.
3. **Choose Manager**: Select your preferred package manager (npm, yarn, pnpm, bun).
4. **Copy**: Click **Copy** for a single command, or **Add to Clipboard** to collect several.
5. **Batch Copy**: When ready, click **Copy All** in the clipboard section at the bottom.

## 🛠️ Tech Stack

- **Structure**: Semantic HTML5
- **Styling**: Vanilla CSS3 (Industrial/Dark Aesthetic)
- **Logic**: Vanilla JavaScript (ES6+)
- **API**: npm Registry API

## 💻 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/jayasriganesh/npmbuilder.git
   ```
2. Open `index.html` in your browser, or use a local server:
   ```bash
   npx serve .
   ```
